# YouTube on Vita v0.58 — First Release

**The real YouTube on TV experience, brought to PlayStation Vita.**

Enjoy YouTube with native Vita controls and touchscreen support, video playback, search, account features and a built-in Add-ons menu for screenshots, sleep timer, display options and local MP4/MP3 downloads.

### Download

- **YouTube.vpk — Recommended.** Extended RAM for a better playback experience.
- **YouTube-Lite.vpk — Lower RAM usage.** Better for keeping other apps in the background.

Install your chosen VPK using VitaShell. Both versions can coexist with their own LiveArea bubbles.

> **Known issue:** Crashes have been reported when switching HD videos, especially during MP3 downloads. Please share logs if you experience this issue.

For screenshots, Add-ons, Google sign-in security, build instructions and technical limitations, see the [README](https://github.com/WolffsRoom/YouTubeOnVita#readme).
